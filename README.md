# Global Health Statistics Dashboard

## Project Overview

An interactive Power BI dashboard designed to analyze global health conditions through healthcare access, mortality, recovery, treatment costs, and population affected across countries and disease categories.

## Data Cleaning

The dataset was cleaned and prepared using Power Query by assigning appropriate data types to categorical and numerical fields and resolving data type issues during import.

## Exploratory Data Analysis

The project includes:

- Correlation Analysis
- Distribution Analysis
- Time-Series Analysis

The analysis explores the relationship between healthcare access and mortality, the distribution of recovery rates, and treatment cost trends over time.

## Data Visualization

The dashboard uses:

- Scatter Plot
- Area Chart
- Bar Chart
- Geospatial Map

## Interactive Dashboard

The dashboard provides:

- Average Recovery Rate
- Average Mortality Rate
- Average Treatment Cost
- Total Population Affected
- Population Affected by Age Group
- Global Population Affected by Country
- Recovery Rate by Disease Category
- Treatment Type Distribution
- Mortality Rate by Disease Category

The dashboard also includes Year and Disease Category filters, tooltips, and drill-through to a Country Details page.

## Key Insights

- Higher healthcare access tends to be associated with lower mortality rates in the dataset.
- Average treatment costs fluctuate over time without a consistent upward or downward trend.
- Population affected is distributed across different age groups and countries.
- Disease categories show differences in recovery and mortality rates.
